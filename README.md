# 臨場（りんじょう）　税務調査体験ゲーム

採用説明会（約30分）で使う、班で手分けして遊ぶ税務調査体験ゲームです。参加者は各自のスマホで架空の喫茶店「浜風珈琲」を調べ、社長の説明を証拠で確かめます。会社・人物・資料はすべて架空です。

## 進め方（司会主導・約30分）

1. **司会の説明（スクリーン・約7分）**：`host.html` を投影。今日の仕事 → お店と社長 → 決算書の**端緒（たんちょ＝不審な点）** → **社長の言い分3つ** → 進め方 → QR。
2. **自分で調べる（スマホ・12分）**：お店の11か所から、証拠がありそうな場所に**当たり**をつけて選ぶ。1人**4か所**まで。見る前に社長に**お願いして承諾をもらう**。見た資料が「どの言い分をくずせそうか」を自分でメモする。
3. **班で相談（6分）**：見つけたことを読み上げ、**班長**を1人決める。班長が言い分ごとに決め手の証拠を1つ選び、「社長に示す」。
4. **答え合わせ（スクリーン・約5分）**：言い分ごとに「答えを見る」を押して確かめる → 結果 → 今日体験した仕事（端緒→当たり→立証）。

担当の割り振りや端末どうしの通信はありません。班の人数は自由です。

## 声

`voice/` に `<ファイル名>.mp3` を置くと、そのセリフで再生されます（なければ声なし）。ファイル名の一覧は `voice/README.md` を参照。スマホでは音のボタン、投影画面では「声：オン／オフ」で止められます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（参加者のスマホで開く） |
| `host.html` | 投影画面（司会が説明に使う。端緒・言い分・QR・タイマー・答え合わせ） |
| `js/case.js` | 事件の中身（端緒・社長の言い分・調べられる場所・決め手）。**新しい事件はここを作り直す** |
| `js/app.js` | スマホの画面（調べる・班で相談・社長に示す・保存・会話） |
| `css/app.css` | 見た目（暗い机の上に紙の資料） |
| `js/assets.js` | 画像の一覧と顔の位置（`tools/make_assets.py` が自動で作る） |
| `assets/` | 背景と人物の画像。元画像は `assets/src/` |
| `js/audio.js` | 効果音とBGM（ファイルを使わず合成）。画面右上でいつでも消せる |
| `js/vendor/` | qrcode.js（QR作成、MITライセンス） |

サーバーは不要です。GitHub Pages でそのまま公開できます。進み具合は各スマホのブラウザーに保存されます（再読み込みしても「続きから」で戻れます）。

## 画像の差し替え

`assets/src/` に同じ名前（`bg_ext` `bg_shop` `bg_office` `boss_grin` `boss_smug` `boss_shock` `boss_panic` `boss_sad` `mori`、拡張子は png/jpg）で置き、`python3 tools/make_assets.py` を実行します。

## 注意

正解はブラウザー側のプログラム（`js/case.js`）に入っています。詳しい人ならソースから答えが分かります（説明会用途として許容）。

## オフライン版

`python3 tools/build_offline.py` で `offline/` にファイル1つで動くHTMLを作ります。ネットがないと文字の形だけ標準の書体になります。
