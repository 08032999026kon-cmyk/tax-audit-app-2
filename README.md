# 臨場（りんじょう）　税務調査体験ゲーム

説明会（学生向け・約30分）で使う、3Dの税務調査体験ゲームです。参加者はグループに分かれ、各自のスマホで架空の喫茶店「浜風珈琲」を調べ、社長の説明の**不審な点**を証拠で崩します。

- **代表**（1グループ1人）：証拠を社長にぶつけられる
- **メンバー**：調べる・相談する（ぶつけるボタンはない）
- 会社・人物・資料はすべて架空です。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（参加者のスマホで開く） |
| `host.html` | 進行画面（司会が投影する。QRもここに出る） |
| `js/data.js` | 事件の中身（主張・証拠・ヒント）。**新しい事件はここを作り直す** |
| `js/world.js` | 3Dの店・事務室・人物・動き |
| `js/game.js` | ゲームの進行 |
| `js/audio.js` | 効果音とBGM（ファイルを使わず合成） |
| `js/vendor/` | three.js r128（3D表示）、qrcode.js（QR作成）。どちらもMITライセンス |

サーバーは不要です。GitHub Pages でそのまま公開できます。

## 注意

正解はブラウザー側のプログラム（`js/data.js`）に入っています。詳しい人ならソースから答えが分かります（1作目と同じく、説明会用途として許容）。
