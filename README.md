# 臨場（りんじょう）　税務調査体験ゲーム

説明会（学生向け・約30分）で使う、イラストで遊ぶ税務調査体験ゲームです。参加者はグループに分かれ、各自のスマホで架空の喫茶店「浜風珈琲」を調べ、社長の説明の**不審な点**を証拠で崩します。

- **代表**（1グループ1人）：証拠を社長にぶつけられる
- **メンバー**：調べる・相談する（ぶつけるボタンはない）
- 会社・人物・資料はすべて架空です。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（参加者のスマホで開く） |
| `host.html` | 進行画面（司会が投影する。QRもここに出る） |
| `js/data.js` | 事件の中身（主張・証拠・ヒント）。**新しい事件はここを作り直す** |
| `js/scene.js` | 画面の見た目（背景を見回す・調べる印・人物の立ち絵・雨やほこり） |
| `js/assets.js` | 画像の一覧と顔の位置（`tools/make_assets.py` が自動で作る） |
| `assets/` | 背景と人物の画像。元画像は `assets/src/` |
| `js/game.js` | ゲームの進行 |
| `js/audio.js` | 効果音とBGM（ファイルを使わず合成） |
| `js/vendor/` | qrcode.js（QR作成、MITライセンス） |

サーバーは不要です。GitHub Pages でそのまま公開できます。

## 画像の差し替え

`assets/src/` に同じ名前（`bg_ext` `bg_shop` `bg_office` `boss_grin` `boss_smug` `boss_shock` `boss_panic` `boss_sad` `mori`、拡張子は png/jpg）で置き、`python3 tools/make_assets.py` を実行します。人物の白い背景や、画像AIが描いた市松模様は自動で消します。調べる印の位置は `js/scene.js` の `SPOTS` で調整します。

## 注意

正解はブラウザー側のプログラム（`js/data.js`）に入っています。詳しい人ならソースから答えが分かります（1作目と同じく、説明会用途として許容）。

## 当日の流れ（約30分）

| 時間 | 内容 | 進行画面 |
|---|---|---|
| 5分 | 説明・グループで代表を決める・QRを読む | タイトル〜進め方 |
| 18分 | 調査タイム（タイマーは進行画面で調整可） | 調査タイム |
| 7分 | ふりかえり・答え合わせ | ふりかえり〜おわり |

## オフライン版

`python3 tools/build_offline.py` で `offline/` にファイル1つで動くHTMLを作ります。ゲームも進行画面も、ダブルクリックで開けます（ネットにつながっていなくても動きます。文字の形だけ、ネットがないと標準の書体になります）。
